SWW v0.9.7 DC-15A scope fix

Root cause:
v0.9.6 attempted to use a 1024x512 image as ONE bitmap-font glyph.
Minecraft bitmap font glyphs are limited to 256x256.

Fix:
- Scope artwork rebuilt as a 1024x256 atlas.
- Atlas contains four 256x256 glyph cells.
- Font maps U+E001..U+E004 to those four cells.
- ScopeManager displays all four glyphs side by side.

Preserved:
- DC-17 unchanged.
- DC-15S unchanged.
- DC-15A weapon balance/zoom unchanged.
- v0.9.6 custom sounds unchanged.
- Existing BlockDisplay blaster bolt unchanged.
- Lightsaber behavior/audio unchanged.
